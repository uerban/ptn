# Native hosting with prebuilt transit

Use matching binaries and web assets from a release that includes `pt-transit`.
This mode needs Python 3.9+, timezone data and the normal hosting proxy. It
installs transit packs without Java, Node, feed downloads, a producer, OSM data
or signing keys. The publisher URL and public keys must come from your operator;
this example does not designate a live public service.

Copy `config.prebuilt.example.json` to a private working directory. Set
`stateDirectory` to a persistent writable directory, choose your advertised
city, and replace `transitPack.source.url` and `transitPack.trustedKeys`. Obtain
public keys independently of the download endpoint. Known cities use the same
presets as the source-driven host; custom cities need `timezone` and
`cityMetadata` as described in the [native host guide](README.md).

Set `memoryBudget` from measurements for your host and city. The example values
are allowances inherited from the reference host, not a claim that a city fits
in 2 GiB. See the [installer guide](../../docs/transit-pack-installation.md) for
disk limits, validation, Docker and retention behavior.

From the extracted archive:

```sh
python3 examples/native/host.py --config /absolute/path/config.json refresh
python3 examples/native/host.py --config /absolute/path/config.json serve
```

Refresh installs the exact city head in signed served-city discovery. It writes
installer state below `<stateDirectory>/prebuilt/transit`; runtime PID/state is
separate under `<stateDirectory>/run`. This is separate from the legacy
producer directory. `dataRootId` belongs to source-driven producer roots and is
not used to bind this installed store. The server authenticates installed data
with the configured public keys before serving.

Serving performs no mirror lookup or installer invocation. It can restart with
the source offline, and even with `transitPack.source` omitted. Refresh failures
exit nonzero without falling back to feed preparation or changing a previously
activated pack. The installer and server enforce their existing signed-data,
resource-limit and atomic activation contracts.

Keep `geometry: false` to install and serve the geometry-free selection. Change
it to `true` and run refresh to add geometry; set it back to `false` and refresh
to remove geometry. The mirror must advertise the requested variant. This
switch retains pack identity. Both variants remain retained locally; no pruning
is enabled. Restarting with geometry disabled can suppress shapes from an
already full install, but only refreshing to the minimal variant avoids those
downloads and validation reads.

Generate the normal PWA city catalog and proxy configuration with `web-config`,
or use the configuration already generated by refresh/serve. Start Caddy using
the native host guide's web root, public-config path and listener settings.
This transit-only mode does not install or configure OSM extras. Independently
managed extras and complete browser behavior without search still need separate
integration and acceptance; the native adapter does not establish those results.

For a foreground updater:

```sh
python3 examples/native/host.py --config /absolute/path/config.json refresh-loop
```

Prebuilt mode defaults to 86,400 seconds between completed refresh attempts,
with ±10% jitter. Set `refreshIntervalSeconds` (integer, at least 60) to override
it. Source-driven mode keeps its existing hourly default. Neither loop changes
publisher build/promotion cadence. Pinning makes installer sync skip fetching.
Use the persistent root directly for status, verification, pinning or rollback:

```sh
bin/pt-transit --root /absolute/state/prebuilt --city CITY status
bin/pt-transit --root /absolute/state/prebuilt --city CITY \
  --trusted-key PUBLIC_KEY_HEX verify
bin/pt-transit --root /absolute/state/prebuilt --city CITY pin
bin/pt-transit --root /absolute/state/prebuilt --city CITY unpin
bin/pt-transit --root /absolute/state/prebuilt --city CITY \
  --trusted-key PUBLIC_KEY_HEX rollback
```

Repeat `--trusted-key` for configured rotation keys. Rollback validates the
previous local selection and pins it; advertising expiry does not prevent
continued offline serving. The running server watches atomic installer
activation, including geometry changes. Preserve installed releases while any
server or in-flight request may use them.

For an offline repository, replace the source object with
`{"kind":"local","directory":"/absolute/path/to/publisher/public"}`. Optional
`transitPack.maxFileBytes` and `maxSelectedBytes` lower per-install limits. They
do not bound total disk use across cache, staging and retained releases.
