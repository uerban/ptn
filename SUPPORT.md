# Support

PTN is maintained on a best-effort basis.

- For reproducible defects, use the GitHub bug-report form.
- For setup, architecture, or usage questions, use the question form.
- For a proposed feature, city, or routing adapter, use the matching issue
  form.
- For security or privacy vulnerabilities, follow [SECURITY.md](SECURITY.md)
  and do not disclose details in a public issue.

Before filing, search existing issues and check the README. Self-deploy operators should include the exact PTN commit or image tag,
container runtime and version, host architecture, selected city, and sanitized
logs.

Never post feed credentials, access tokens, private registry addresses, or a
person's precise location or trip history. Replace them with explicit
placeholders in logs and reproduction steps.
